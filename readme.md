# SerialPlotter

网页端实时数据可视化分析工具，支持串口、TCP 和 UDP 数据流的解析、监视与波形展示。

![License](https://img.shields.io/badge/License-CC%20BY%20NC%20SA%204.0-blue.svg)![JavaScript](https://img.shields.io/badge/JavaScript-vanilla-yellow.svg)![Platform](https://img.shields.io/badge/platform-Web-green.svg)

## 1 项目简介

SerialPlotter 是一个无需后端框架的浏览器端工具，适合调试单片机、传感器、上位机协议和网络数据流。它可以把接收到的数据实时绘制成波形，支持时域、频域、通道配色、统计信息、发送面板和配置导入导出。

界面英文和数字沿用等宽字体，中文使用随项目附带的开源 Noto Sans SC。字体文件和独立授权说明位于 [`assets/fonts/`](assets/fonts/README.md)，离线打开页面也无需在线字体服务。

## 2 主要功能

- 串口通信：基于 Web Serial API，适合现代 Chromium 系浏览器。
- 网络通信：通过本地 `bridge.js` 提供 TCP Client、TCP Server 和 UDP 能力。
- 波形显示：支持时域图和频域图切换，频域模式内置 FFT。
- 频域去直流：可选在 FFT 前移除 DC 分量。
- 多通道显示：右侧统一通道面板支持原始通道、运算通道、常量数组和差分方程系统；名称、颜色和运算定义全局共用，各控件独立选择可见通道。
- 采样缓存最多保留 360 万帧、50 个原始通道；新增运算及参数通道后编号最多为 CH256。波形监视台的默认可见窗口独立设置，最多 65536 点。缓存按需分配，实际内存随保留数据增长。
- 统计信息：波形监视台显示实际绘图帧率；单通道时还显示最大值、最小值、峰峰值、均值、标准差、主频和周期。
- 交互查看：支持十字光标、双轴拖动条、滚轮缩放、矩形框选放大和手动 Y 轴范围。
- 采集方式：通道数值、Hex 和文本；数值帧支持头部、尾部、8-bit 校验、字节序和多种数据类型，原始字节可按空闲间隔或文本换行断帧。
- 控件工作区：可添加多个独立波形和字节流控件，拖动、栅格对齐、步进缩放，右侧配置选中实例。
- 发送面板：全局共用通讯连接，支持 Hex/Text、文件发送、定时发送。
- 配置管理：支持本地保存、导入、导出。

## 通道运算与系统

选中波形控件或通道数值模式的字节流控件，在右侧“通道配置”选择类型并新增通道。展开 CHxx 后编辑定义，点击“删除通道”左侧的“应用公式”生效；非法表达式在该通道下方提示，最后有效定义继续使用。勾选“重建历史数据”时异步更新受影响通道的历史波形；未勾选时保留历史，只更新后续采样。勾选后再次应用同一公式，也可重建此前保留的旧结果。

拖动用户新增通道的 CH 编号到另一新增通道，可调整排列顺序；其他通道依次顺移，原始数据通道固定。编号改变时，已应用公式及未应用的编辑内容中的 CH 引用同步更新，保持原有依赖关系。名称、颜色、历史结果、积分/差分/filter 状态及各控件可见性随信号移动，搜索和导出选择同步更新。分类筛选时仍可排序，未显示的通道保留在全局顺序中；排序结果随配置保存。

| 类型 | 示例 | 含义 |
| --- | --- | --- |
| 运算通道 | `(CH01+CH02)/2` | 四则运算、括号及正负号 |
| 历史索引 | `CH01[0]-CH01[-1]` | 当前值减上一采样值；不可取未来值 |
| 差分 / 积分 | `diff(diff(CH01))`、`int(CH01)` | 按采样点计算，不乘除时间间隔 |
| 常量数组 | `[0]=1,[1]=-2.3` | 从 0 开始连续编号；标量运算用 `CHxx[1]` 等显式索引 |
| 因果卷积 | `filter(CH01,CH02)` 或 `filter(CH02,CH01)` | CH02 为常量数组，初始不足的信号历史补 0 |
| 差分方程系统 | `y[n]=x[n]+0.5*y[n-1]` | x 为输入、y 为输出；另填初始状态 `y[-1]=0` |
| 系统输出 | `filter(CH01,CH03)` 或 `filter(CH03,CH01)` | CH03 为系统或常量数组；参数按类型识别，每个 filter 调用拥有独立状态，交换写法不改变系统初始状态 |

差分方程也可使用 `x[0]`、`x[-1]`、`y[-1]` 等写法。用到输入或输出的第 k 阶延迟时，须填写从 -1 到 -k 的所有初始状态，用逗号或换行分隔。禁止未来输入和当前输出反馈；循环通道依赖及不存在的引用会报错。常量数组和系统不作为逐帧数值列或 CSV 列，可以在“系统响应”中绘制；通过运算生成的输出通道可以显示、搜索和导出。

删除自建通道后，后续通道编号自动顺延，公式引用、名称、颜色、各控件可见性及搜索／导出通道选择同步更新；剩余通道的历史数据与运算状态保留。仍被公式引用的通道不能直接删除，需先修改依赖公式。

### 系统响应与幅相绘图

波形“显示方式”按“显示内容、采样与响应、横轴设置、纵轴设置、FFT 设置”分组，不适用的配置及空分组随绘图模式隐藏。显示对象可选择“采样波形／系统响应”，分别保存可见通道和视口。采样波形显示原始与运算通道的采集结果；系统响应显示常量数组与差分方程系统，不需要连接设备，也不会写入或清空采集缓冲。通道配置的分类下拉框可筛选原始数据、运算通道、常量数组、差分方程系统或全部分类，筛选不会改变勾选状态。

“采样与响应”中的点数默认全局共用，保存为 `global.plotWindowPoints`：控制采样波形时域窗口、实时 FFT 的最新输入范围、暂停 FFT 的默认范围及系统响应频率网格，上限为缓存容量与 65536 中较小者。暂停后框选时域范围仍优先用于 FFT。只有“系统响应＋时域图”的点数按控件独立保存为 `plotResponseTimePoints`（2–65536），不随缓存缩容变化，也不改变幅相频率网格。输入标签注明共用范围；切换模式时恢复对应值。旧配置没有全局点数时，仍取第一个波形原显示对象的点数。

选择具体通道分类时，“新增通道”类型选框自动匹配该分类并锁定，保留选框显示；切回“全部分类”恢复自由选择及此前的选择。原始数据通道由帧解析生成，筛选原始数据时禁止手动新增。波形和字节流数值控件均遵循此规则。

- **时域图：**系统以零初始状态的单位脉冲输入计算响应，配置的初始状态仍用于实际 `filter` 运算。左侧为 `[0]`，向右依次为 `[1]`、`[2]`；缩放和平移只改变显示密度，左侧零点不跟随接收时间。常量数组直接显示各数组元素。
- **幅频图：**原“频域图”配置兼容为幅频图。纵轴刻度统一提供“原幅值-线性、原幅值-对数、dB：10lg(幅值)、dB：20lg(幅值)”；dB 已作对数换算，其刻度保持线性。新控件默认 dB：10lg(幅值)。横轴刻度统一提供“Bin-线性、Bin-对数、Hz-线性、Hz-对数”，幅频与相频默认 Hz-对数。采样 FFT 默认去直流。原幅值与 dB 分别保存自定义 Y 轴范围，旧配置显式保存的单位、刻度、去直流及 dB 系数保留。
- **相频图：**纵轴设置中的“纵轴刻度”位于“展开相位”上方，可选角度（°）或弧度（rad），新控件默认弧度；刻度、光标读数、自定义 Y 轴范围和纵轴缩放同步换算。“展开相位”默认勾选，取消勾选时折叠至 −180°～180°（−π～π rad）。各波形控件独立保存相位单位，已保存的角度选择保留。采样相位相对于当前 FFT 输入窗口首点；零幅值频点不制造相位。
- **系统频率：**按常量数组或线性差分方程直接计算传递函数，不加窗、不去直流、不作采样谱的单边幅值归一化。可单独设置响应采样率；0 表示未设置，此时显示 `cycles/sample`，范围为 0～0.5。设置采样率后可换算 Hz，亦可按频率网格显示 Bin。
- **适用范围：**标准系统幅相响应仅适用于线性、无独立偏置的差分方程。不适用的定义仍可查看单位脉冲输入下的时域结果，幅相图给出提示；极点、溢出或无法定义的相位留空。系统视图不对应接收字节或系统时间，定位搜索仅适用于采样波形和字节流；导出仍导出实际采集数据。

静态响应缓存按定义与响应点数复用，实时接收不会重算系统图；多个系统采用相同频率网格。修改定义后自动更新响应，与采集历史是否重建相互独立。

差分首点、缺失的历史索引、除零或溢出结果为空，采样位置继续推进，时域曲线在此断开，CSV 单元格留空。积分遇到无效输入时保留累计值，后续有效输入继续累计。FFT 保留采样位置并将无效位置填零；整个窗口均无效时不产生频谱。

“重建历史数据”与帧解析面板共用开关：关闭时保留已经计算的历史结果，新公式或系统从下一采样点开始，受影响的差分、积分及系统状态重新初始化；开启时异步重算受影响通道及其下游的保留历史，进度在工作区上方显示。原始样本、字节及其他通道保持原值。修改常量也遵循此规则。

删除被其他公式引用的通道前，需要先修改或删除引用它的公式。原始通道数量变更与新增编号冲突时会明确报错，不会让公式静默引用另一条数据。旧配置中的线性变换仍可兼容读取，新的通道面板不再提供放大/偏移编辑项，可用运算公式表示，例如 `CH01*2+3`。

## 3 环境要求

### 3.1 浏览器

建议使用 Chrome 或 Edge 等 Chromium 内核浏览器。

- 需要支持 Web Serial API 才能使用串口模式。
- 建议通过本地 HTTP 服务或 HTTPS 方式打开页面，不要只依赖 `file://`。
- Firefox、Safari 目前不适合本项目的串口模式。

### 3.2 Node.js

如果需要使用 TCP/UDP 模式，请安装：

- Node.js 14 或更高版本
- npm 6 或更高版本

## 4 运行方式

### 4.1 网络访问（体验与试用）

适合初次尝试使用，直接访问 https://yssickjgd.github.io/serial_plotter/ 即可。

### 4.2 本地访问（强烈推荐）

如若希望长期离线使用，则可以将仓库下载到本地：

```bash
git clone https://github.com/yssickjgd/serial_plotter
```

然后，在浏览器中打开仓库内的 `index.html` 即可。前端无需构建或安装依赖；TCP/UDP 模式仍需启动本地 Bridge。

### 4.3 启用 TCP/UDP 网络功能

本项目还支持网络数据流的监听、解析、通信、绘图.如若使用该功能，则须克隆该仓库到本地：

```bash
git clone https://github.com/yssickjgd/serial_plotter
```

而后，需要在该仓库内执行下述两条命令，开启服务。注意！使用期间不能关闭该界面：

```bash
npm install
npm start
```

默认会启动本地 WebSocket Bridge，仅监听 `ws://127.0.0.1:8081`。TCP Server 与 UDP 的设备监听端口仍按页面配置工作。

## 5 使用方法

### 5.1 串口模式

1. 打开左侧“通讯”选项卡。
2. 选择“原生串口 (Web Serial)”模式。
3. 设置波特率、数据位、停止位和校验位。
4. 点击“连接”，在浏览器弹窗中选择串口设备。
5. 从左侧“控件”拖入波形或字节流，也可点击“添加”；接收数据后配置各控件的解析和显示。

### 5.2 TCP Client 模式

1. 启动 `node bridge.js`。
2. 在“通讯”里选择 “TCP Client (Bridge)”。
3. 填写远端 TCP Server 的 Host 和 Port。
4. 点击“连接”。

### 5.3 TCP Server 模式

1. 启动 `node bridge.js`。
2. 选择 “TCP Server (Bridge)”。
3. 填写要监听的本地端口。
4. Host 字段可以忽略，桥会在 `0.0.0.0` 上监听该端口。
5. 让外部 TCP 客户端连接这个端口即可。

### 5.4 UDP 模式

1. 启动 `node bridge.js`。
2. 选择 “UDP (Bridge)”。
3. 填写远端 Host 和 Port，这表示发送目标。
4. 填写本地监听端口，用于接收 UDP 数据。
5. 如果本地端口留空，程序会优先使用 Port 作为默认监听端口。

### 5.5 控件工作区

- 首次使用为空白工作区；旧配置自动迁移为原来的两个监视台。空工作区也继续采集，之后添加控件可以读取仍保留的历史。
- 可添加同类型多个实例，分别显示不同通道、时域/频域、Hex/文本。点击或键盘聚焦控件后，右侧显示它的属性；点击工作区空白处取消选择。
- 点击“添加”或从控件库拖入时，新控件沿用同类型控件的当前宽高；多个同类型控件中优先选择本次会话最近激活过的实例，拖入预览使用相同尺寸。没有同类型控件时使用默认尺寸；位置自动避开已有控件，恢复保存的布局时保留原尺寸。
- 标题可编辑，删除只移除该控件。“恢复布局”整理现有控件，不重新创建已经删除的实例。刷新恢复控件清单、布局和设置。
- 新控件默认宽高取当前 10/20/40 px 栅格步进的整数倍。标题拖动和八向缩放仅按工作区栅格对齐，允许保留一个步进的间隔；到达其他控件时按防重叠约束停止。按 Esc 撤销拖动。没有空位时向下扩展工作区。标题方向键移动，Shift＋方向键缩放，Delete 删除。
- 拖动或放大控件超出右边缘时，工作区也会向右扩展。通过底部横向滚动条、Shift＋滚轮或触控板横向滑动查看；窗口变窄时保留已有位置和尺寸。“恢复布局”按当前可见宽度重新整理控件。普通滚轮保留波形缩放及字节记录滚动。
- 鼠标位于工作区时，Ctrl＋滚轮及 Ctrl＋= / Ctrl＋- 只缩放工作区，范围为 25%～500%；工具栏可直接输入整数百分比，如 81%、155%。滚轮以鼠标位置、键盘以可见区域中心缩放，跨过完整适配比例时自动吸附；适配包围框包含四周 10 个逻辑像素留白，比例向下取整。左右侧栏和底部工具保持原尺寸，比例随布局保存，控件逻辑位置、尺寸、采样范围及栅格不变。
- 在工作区空白处拖动框选多个控件，再拖动其中任意控件的标题即可整体移动；组内相对位置不变，栅格和禁止重叠约束继续生效，Esc 撤销。右键空白处交替执行“以可见区域中心恢复 100%”及“完整适配全部控件”；若 25% 仍放不下，以右键点击位置为锚点缩至 25%。控件内部右键行为保持原样。
- 完整适配只为逻辑零点保留约定的 10px 留白，不为强行居中而展示大块负坐标区域；顶格排列的控件仍贴近工作区顶部，全部控件保持可见。
- 在右侧修改控件标题后，鼠标移出标题输入区域或输入框失焦即应用，切换控件前也会保存；空标题恢复原名称。
- 工作区文字使用浏览器原生布局缩放，波形按工作区比例与屏幕像素密度重新绘制，放大后保持清晰；暂停时改变工作区比例也会立即重绘。
- 数值帧规则与通道名称全局共用，波形颜色、可见性、变换和显示设置独立；字节流的断帧、字符集、排版和可见通道独立。
- “每个来源最大帧数”分别限制各解析源和 TX 保存量。原始帧默认最多 1 MiB，超限完整分段保存并标注原因，连续文本和搜索不因分段中断。
- “重建历史数据”开关各处同步。规则改变只重建受影响源；关闭时该源从当前接收位置重新记录，其它控件继续采集。全局清空清除全部源、TX、搜索和未完成重建。
- 定位与搜索在暂停后可用，来源自动跟随当前激活控件，不再提供来源选择项；就近参考控件仍可独立选择。切换激活控件时清除旧搜索结果并更新搜索类型和默认时间，取消未完成的搜索；没有激活控件时不可操作。时间定位和搜索按原始字节位置联动所有控件，超出保留范围会提示。
- 导出位于左侧与“通讯”“控件”并列的“导出数据”栏目。独立选择基础原始记录、共用数值缓冲区或字节流解析来源，激活其他控件不改变导出来源；数据来源和各格式的选项分别保存。
- 底部“全局发送”常驻展开，默认四行输入。拖动其上方分隔条可向上扩大输入框，最少保留四行，并为工作区预留空间；分隔条聚焦后可用上下方向键调整、Home 恢复最小高度。所有字节流共用成功发送记录。

## 6 界面说明

按 **P** 可切换全局暂停／恢复捕获，大小写均可；长按不连续切换。在输入框、下拉框或可编辑内容中输入时不触发，Ctrl／Alt／Meta 组合键及输入法组字期间也不触发。

### 6.1 波形监视台

- 时域图：显示通道采样值；横轴可选采样点或秒（s）。
- 频域图：可选择无窗、Hann、Hamming、Blackman 或 Flat-top 窗，默认 Hann。FFT 前可选去直流，频谱按窗的相干增益校正为单边线性幅值。横轴可选 FFT 频点编号或 Hz，并可选线性或对数间距；纵轴可选线性幅值或对数间距的幅值（不是 dB）。对数横轴从第 1 个频点开始。对数纵轴自定义下限为 0 时，零附近采用线性刻度，线性区间上限为当前可见频谱峰值与自定义上限中较小者的 1%，以上连续过渡到对数间距；全零频谱采用线性刻度。刻度和光标始终显示原幅值，缩放期间固定过渡位置，右键重置后重新自适应。正数下限和自动范围继续采用标准对数刻度，零幅值绘在显示下界。
- 实时采集时，FFT 使用波形监视台窗口内的最新样本；暂停捕捉后，FFT 使用时域图当前 X 轴可见范围内的样本。暂停期间可切到时域图滚动或缩放，再切回频域图查看对应频谱；恢复捕捉后重新使用最新窗口。单通道频域统计也采用相同的数据范围。
- 左侧“通讯 → 缓冲区设置”的每源容量分别控制该源的保留帧数；采样波形窗口及幅相频率网格共用点数，限制为容量与 65536 中较小者。减小容量自动缩小采样窗口，右键恢复最新窗口；系统响应时域长度独立，不受容量影响。
- 公共工具以当前激活控件为来源，暂停后可定位和搜索。系统时间精确到 1 ms，默认当前控件最新保留帧时间；相对时间以 s 为单位，零点为来源按接收顺序保留的第一帧。各控件按原始字节区间同步，高亮时间行并绘制波形竖线。字节流 Hex/文本设置不会停止共享数值采集。
- 工作区添加、拖动、缩放、删除及恢复布局的操作见 5.5。多控件布局和实例设置随配置一起保存；旧双监视台布局自动迁移。
- 波形和字节流控件使用一致的标题与统计样式；宽度不足时统计项完整换行，没有单通道统计时收起空行。
- 所有互斥选项使用下拉框；鼠标悬浮时滚轮向下选择下一项、向上选择上一项，边界处停止并跳过禁用项，侧栏中的 Ctrl＋滚轮仍用于浏览器缩放。独立开关保留复选框。切换时域/频域后只显示对应设置，选择自定义 Y 轴范围后才显示边界输入框。
- 时域和频域分别保存自动/自定义 Y 轴策略及最小、最大值，切换模式时输入框恢复该模式的设置。自定义范围要求有限数值且最大值大于最小值；频域对数轴允许最小值为 0，最大值必须为正数。无效范围会显示原因并暂用自动范围；重新应用 Y 轴设置会清除当前模式的临时框选缩放。旧配置的共用策略仍可读取，新配置使用 `plotYScaleModeTime`、`plotYScaleModeFreq` 分别保存策略。
- 左侧“通讯”“控件”并列；右侧配置并导出选中实例，数值帧规则和通道名称明确为共享设置。每个波形的 `y = kx + b` 变换参与绘图、FFT、光标、统计、搜索与该实例 CSV，原始数据不变。
- Hz 和 s 使用共享数值源的稳定采样率估计换算，不再直接使用每秒接收帧率。估计采用数据块的单调到达时间和有效数值帧数，至少观测 2 秒，最近窗口最长 10 秒；0.2% 以内的短时变化保持原值，更大的变化持续 3 秒后更新。它仍是接收时刻的估计，不能替代设备提供的准确采样时钟；未知时显示 `-- Hz` 或 `-- s`。暂停、断开不把空闲时间计入采样率。
- 鼠标悬浮时，两种模式使用一致的提示框：时域显示时间（s）与采样点索引，频域显示频率（Hz）与 FFT Bin，始终同时显示两种横轴信息，不受横轴单位选项影响。采样点索引与时域横轴一致，从当前保留的第 0 点开始；通道交点数值仍单独显示。
- 单通道时会显示统计信息。
- 单通道统计的主频单位跟随频域横轴（Hz/Bin），主周期单位跟随时域横轴（s/Sample），在两种绘图模式下均有效。Hz 和 s 使用最近测得的采样率换算，未知时显示 `--`；Bin 和 Sample 无需采样率即可显示。
- 波形监视台的“绘图帧率”在时域统计完成的画布重绘，在频域统计实际更新并呈现的新频谱，重复绘制缓存频谱不计入；字节流监视台的“帧率”统计接收帧数。暂停后无新绘制时前者为 `0 FPS`。
- 持续接收时，频谱最短每 100 ms 更新一次；仅有新采样而频谱尚未到期时不重复绘制缓存频谱。鼠标操作和显示设置变化仍可触发即时重绘。实际帧率取决于通道数、采样点数和设备性能。
- 统计栏优先使用通道自定义名称，未修改名称时显示默认的 CH01、CH02。
- 在绘图区按住鼠标左键拖出矩形，松开后放大框内的横轴与纵轴范围；拖动过小不会触发缩放。时域和频域均可使用。
- 鼠标位于绘图区或下方 X 轴刻度带时，滚轮缩放横轴；位于右侧 Y 轴刻度带时，滚轮缩放纵轴。横轴放大后可拖动底部滚动条，纵轴放大后可拖动右侧滚动条。
- 实时采集时，横轴滚动条离开最右侧后固定当前样本窗口；新帧不会改变所选波形，直到该窗口的最早样本被缓冲区淘汰，才从左侧随旧帧淘汰而更新。拖回最右侧或右键恢复最新数据跟随。
- 在绘图区点击右键恢复完整横轴范围，并撤销框选或滚轮带来的纵轴缩放。原有的手动 Y 轴范围会恢复。

### 6.2 字节流监视台

日志颜色统一如下：

- 蓝色：接收成功 `RX`
- 黄色：接收错误 `RX[原因]`
- 绿色：发送成功 `TX`
- 红色：发送错误 `TX[原因]`

说明：

- 未通过验证的数据会显示时间戳。
- 错误原因会直接附在 `RX` 或 `TX` 后面。
- 较长的 Hex 记录会随监视台宽度自动换行，续行与第一行 Hex 字节的起始列对齐（普通记录为 `RX ` 或 `TX ` 后）。
- 在底部自动跟随最新记录；向上滚动后固定所查看的记录，滚回底部或在记录区右键恢复最新位置和自动跟随，右键不弹出菜单。记录超出保留窗口后会显示当前最早的记录。
- 鼠标拖选记录后可按 `Ctrl+C` 复制。选中文字后保留当前文字和选区，接收、缓存及滚动范围继续更新；虚拟记录位置保留数值精度，避免长时间接收时选中文字逐渐漂移。清除选区后仍停留在所查看的位置，可向下滚动查看新记录，只有右键记录区才恢复最新位置和自动跟随。
- 主动滚动查看历史会结束当前文字选区，但保持停止自动跟随的状态。滚动定位使用已显示记录的范围；拖动原生滚动条期间固定映射及滑块大小，松开后更新到当前保留范围，并保持所查看文字的位置。跨越普通／虚拟布局阈值也不使用新增记录重新解释旧滚动条；若整个拖动范围已被缓存淘汰，则显示当前最早的记录。
- 时间定位和搜索优先将目标居中；靠近保留数据首尾时按边界对齐，不人为补出无样本的时域范围或首尾空白记录。样本少于窗口点数时用实际保留样本填满波形区域，配置点数保持不变；暂停 FFT 与实际时域窗口使用同一有效范围。
- 接收显示及搜索类型由字节流“帧解析”中已应用的采集方式决定。通道数值显示原始解码值，Hex 显示原始字节；文本按字符集解码，非法编码和不可打印控制字符显示白色 `�`。CR/LF/TAB 保留可见转义且不计失败，统计栏显示失败数、总字符数和比例。发送格式和间隔单位使用 Hex/Text、s/Hz 下拉框；旧配置的 ms 换算为 s。
- 通道数值按字节流显示区的当前宽度自动分列，个位通道编号显示为 `CH01`～`CH09`。采用科学计数法，正数预留负号位置，同列数值按 `e` 对齐，有效数字位数可在显示方式中配置。数值位数变化不挤动后面的通道，调整窗口或侧栏宽度后自动重新排版；窄窗口内自动换行，原始采样和搜索精度不受显示精度影响。
  分列按所选有效数字位数计算，预留符号与三位指数空间，充分使用可用宽度。持续接收时查看历史记录固定其屏幕位置，新增帧及缓存淘汰不会让保留的记录上下抖动；返回底部或右键记录区后继续跟随最新数据。
- 文本字符统计直接计数，不创建显示或搜索用的位置对象；UTF-8、ASCII 和 UTF-16 的非法字节直接判定，减少异常处理开销。历史文本复用行高信息，只为可见记录生成换行和高亮内容；新字节补全跨帧字符、记录被覆盖或宽度改变时更新相应布局。原始字节、白色替代字符及失败统计规则保持一致。
- 暂停捕捉后可按接收显示格式搜索十六进制字节、解码文本（都可跨帧匹配，文本支持中文和多字节字符）或指定误差范围内的解码通道数值。文本搜索可勾选“区分大小写”，默认勾选；修改该选项后清除旧结果，下次操作重新搜索。数值搜索默认检查全部通道，也可展开通道复选列表，仅搜索选中的多个通道。通道选项同时显示编号与自定义名称（如 `CH01 · acc_x`），修改名称后同步更新；长名称可悬浮查看完整文字。通道编号及默认名称统一为 `CH01`～`CH09`、`CH10`～`CH50`，旧配置中的默认名称自动兼容，自定义名称保留。
- 搜索按钮依次为“就近搜索”“上一个”“下一个”；“就近依据”可下拉选择波形或字节流，默认字节流，会话内跨采集方式保留选择。处于最新跟随状态时以最新帧为起点，查看历史时使用窗口中心；频域模式使用保留的时域窗口，字节流按实际换行后的记录显示区确定中心，不以点选行作为起点。两种断帧不同的视图按源字节位置映射参考帧、同步定位与波形竖线，空波形时以最新字节帧为参考。
- 没有选中的搜索结果时，先确定就近结果：首次“上一个”选择其后一个结果，首次“下一个”选择其前一个结果。已有高亮结果后，“上一个”选择较早的结果，“下一个”选择较新的结果，均首尾循环。移动窗口、时间跳转或切换就近依据不会清除当前结果，点击“就近搜索”才按新位置重新定位；修改搜索条件则清除旧结果，下次点击按钮重新搜索。相同条件复用搜索结果，异步搜索使用点击按钮时的位置。
- 搜索按原始字节区间同步所有仍保留目标的控件。字节流高亮和波形竖线使用来源配置的命中颜色；范围外控件显示说明。发送区独立于字节流控件，输入框高度可通过上方分隔条调整。
- 接收速率按真实接收到的数据块统计，不会因为错误帧重复放大。
- 帧尾不匹配时，错误记录显示重同步过程中实际丢弃的字节，不重复列出相互重叠的候选帧；尚不足一帧的末尾字节会继续等待输入，暂停或断开时以“帧未完整”记录一次。
- 大于 5 万帧的 CSV 使用 Chrome 或 Edge 的文件保存接口分批写入，避免在内存中拼接完整 CSV。建议暂停采集后导出，以免导出过程中最早记录被覆盖。

右侧“字节流”选项卡中可配置：

激活字节流监视台后，右侧“显示方式”内提供“显示方式”“记录配置”“颜色配置”三个小节；颜色使用小色块和紧凑行距。“通道配置”独立选择数值模式中显示的 CHx＋名称，支持全开／全关，默认全部显示，并保存到配置文件；与波形通道勾选互不影响，不改变采样、搜索或导出。Hex／文本模式没有通道数值，该栏目显示说明。

- **显示方式：**Hex 每行字节数自动适应宽度，或选择 8、16、32 字节；可按 2、4、8 字节分组、显示帧内或接收字节流偏移，并附加 ASCII 对照。启用对照时，末行不足的 Hex 字节列留空，使 ASCII 列与完整行对齐。文本可选择白色替代字符或非法字节转义、可见换行转义或实际换行，以及 Tab 转义或 4、8 个空格。
- **通道数值：**字节流记录统一采用科学计数法，按 `e` 位置对齐，正数预留负号空位。有效数字位数包含整数位，可设为 1～17 位，默认 6 位，例如 `CH01= 1.23456e+2`、`CH02=-1.23456e-3`。修改后已有记录立即更新，设置保存在本地及 JSON 配置中；只改变显示精度，不改变原始样本、数值搜索、波形、统计或 CSV 导出。非有限值显示为 `NaN`、`Infinity`、`-Infinity`。
- **时间与刷新：**时间戳可显示时分秒和毫秒、完整日期时间、相对时间或隐藏；相对时间从当前保留的最早 RX 帧起算。RX/TX 标记可隐藏。字节流有变化时在下一次浏览器绘制前更新，不设置固定刷新率上限，同批到达的数据合并显示，原始记录完整保留。旧配置中的刷新率字段自动忽略；滚动查看历史时保持已选位置，无新数据时不持续刷新。
- **关键词与颜色：**关键词逐行输入，可选择 Hex 或文本。Hex 按原始字节匹配，文本按所选字符集解码后匹配并支持大小写开关；数值模式下文本关键词匹配 `CHx=数值`，Hex 匹配到原始帧时高亮该记录。可分别设置关键词、RX、TX、RX 错误、TX 错误、RX 无效字符及 RX 超出分段上限的文字颜色，以及当前搜索命中和其他搜索命中的背景颜色；波形搜索竖线同步采用对应颜色。搜索高亮优先于关键词，RX 无效字符采用独立颜色（默认白色），标注“超限”的 RX 记录默认黄色；分段记录仍是有效接收记录，不增加校验失败计数。
- **筛选与折叠：**分别筛选 RX、TX 和错误记录。长帧可折叠为指定行数，展开／收起按钮位于首行右侧，不额外占行；正文预留按钮位置，窄窗口中也可操作。
- **长帧历史滚动：**大量记录使用虚拟显示，仅创建当前可见内容。Hex／文本滚轮按实际行高移动，可逐行查看长帧；拖动滚动条用于快速定位历史。最顶部可查看首帧开头，切换折叠会约束帧内偏移，保持当前位置可见，不删除记录。
- 显示设置立即生效并保存在本地及 JSON 配置中。旧配置沿用原有显示效果；调整这些设置不会重建或清空历史，不改变原始字节、字符失败统计或导出内容。搜索仍覆盖完整保留记录；定位到被筛选或折叠的 RX 帧时临时显示并展开该帧。

### 6.3 采集格式与应用

- 不再单设“采集配置”栏目。波形“帧解析”固定按通道数值解析，设置数据类型、端序、通道数、帧首、帧尾和校验；字节流“帧解析”选择 Hex、文本、通道数值或自定义帧（暂未开放），并设置原始断帧、字符集。下拉框和开关自动应用，文本或数字输入完成后失焦或按 Enter 应用。无效输入保留当前格式和数据；未完成输入不覆盖已保存配置。帧首、帧尾和校验未启用时隐藏相应设置。
- 所有实例读取统一采集服务；空工作区仍采集数值及基础原始记录。数值规则共用，原始断帧与字符集按字节流实例设置。同规则同起点的原始源复用缓存，物理 RX 字节仅计一次。
- Hex 仅按空闲间隔断帧，间隔固定为 `0.001 s`，不提供间隔输入框。文本可选空闲、`\r`、`\n`、`\r\n` 或 `\n\r`，默认空闲；选择空闲时同样固定为 `0.001 s`。空闲按浏览器收到数据块的到达间隔判断，计时器延迟时也先检查期限；它不能恢复设备在同一浏览器数据块内的发送间隔。
- Hex／文本记录数不等于设备的数值采样帧数：同一接收块可包含多个采样帧。间隔不足 1 ms 的接收块合并，到达原始帧单段字节上限时分段保存；例如 1024 字节上限限制单条长度，不限制历史条数。暂停或断开时保存尚未结束的尾部记录，原始字节保持完整。
- Hex 模式不显示空的“原始数据断帧”配置组；文本模式显示字符集及断帧方式。字节流选择通道数值时，在当前“帧解析”页直接显示数值解码、帧首、帧尾和校验设置，不再跳转；这些规则仍与全部波形及数值字节流控件共用。
- 换行符保留在前一帧中，空行也保留，支持跨块分隔符及 UTF-16 完整字符断帧。每条记录取其首个数据块的系统时间。暂停或断开会保存尾部字节；换行模式下未结束记录标注“帧未完整”，仍可定位及搜索。
- 文本字符集支持 UTF-8、严格 ASCII、GBK（兼容 GB2312）、GB18030、Big5、UTF-16LE、UTF-16BE、Shift-JIS、Windows-1252，默认 UTF-8。显示及搜索使用同一解码和原始字节映射，中文换行与搜索高亮保留源字节位置。
- 文本字符集及断帧方式由所有字节流控件全局共用，修改后按“重建历史数据”开关处理文本数据源；Hex 固定空闲断帧及数值源不受影响。各实例仍独立选择采集显示模式、颜色、筛选及排版。
- “重建历史数据”各实例共用并同步。开启时仅异步重建受影响源并显示进度，数值规则更新影响全部数值视图；关闭时仅受影响源从当前接收位置开始，其它源与 TX 保留。无效设置保持当前解析。
- 大于等于 512 KiB 的历史会按需使用后台线程：并行解码数值、统计文本、准备长记录显示，以及合并 Hex 历史帧的字节片段。最多使用浏览器报告的逻辑处理器数减二个线程；不足三个、不支持后台线程或线程失败时自动异步回退。Hex 在主线程按原始到达时间和断流边界确定帧归属，字节合并分批交给后台线程，结果按原顺序写入；未结束的尾帧恢复到实时解析器继续接收。字符分块遵循编码边界，原始字节不会被转移或改写。小历史沿用异步分片，避免线程启动开销。
- 重建在源内完成历史快照及新数据追赶，其他源继续实时采集。所有任务共用线程池，最多使用逻辑处理器数减二；少于三个时用主线程异步分片。断流边界随历史重放，清空或销毁后的旧任务不能回写。
- 文本统计按字符统计非法编码及不可打印控制字符，正常换行、回车和 Tab 不计失败。相同源与编码复用增量统计。原始归档按各源仍需要的最早字节位置保留。
- 长文本分批准备并显示进度，监视台只渲染可见行；原始字节、全部记录及搜索映射仍完整保留。
- 配置新增 `captureMode`、`textEncoding`、`textBoundary`、`idleGapSeconds`。旧配置缺少这些字段时恢复通道数值、UTF-8、空闲、`0.001 s`。字节流控件读取旧配置后也统一使用 `0.001 s`，保留 `idleGapSeconds` 字段用于配置兼容。


### 6.4 数据导出

- 在左侧“导出数据”先选择格式，再配置记录范围及对应选项。四种格式始终可选：原始字节（.bin）、空格分隔且按帧分行的 Hex 文本（.hex）、文本（.txt）及通道表格（.csv）。CSV 默认使用共用数值缓冲区，也可选择其他原始记录按独立导出参数解析；其他格式默认选择基础原始记录。切换记录范围不会改变格式，CSV 与其他格式分别记住上次范围。
- 记录范围包括“基础原始记录”“成功解析的数值帧”及独立字节流记录。基础原始记录按 1 ms 空闲断帧，数值帧使用全局数值帧规则；字节流记录沿用该实例的断帧规则。共用同一缓冲区的来源合并显示，并提示关联控件；删除关联控件不会删除仍共用的来源。
- CSV 导出通道直接展开，以紧凑网格复选，默认全部，选择独立于波形及字节流的通道可见性。导出共用缓冲区的原始及运算通道，不应用控件显示变换；可勾选时间戳加入 `Timestamp` 列，采用含毫秒的 ISO 8601 UTC 时间（末尾 Z）。
- bin、Hex 文本及文本可选择 RX、TX 或 RX＋TX，合并时按记录顺序导出；CSV 仅包含接收数值。仅导出 TX 时隐藏 RX 记录范围选择，即使对应 RX 来源已删除也可导出。Hex 文本和文本可选时间戳及 RX/TX 标记，bin 仅保存原始字节，不保存断帧边界或额外标记。
- 文本导出分别选择原始字节的解码字符集和输出文件编码，支持 UTF-8、ASCII、GBK、GB18030、Big5、UTF-16LE、UTF-16BE、Shift-JIS、Windows-1252。输出默认 UTF-8；无法用目标编码表示的字符会报错，不静默替换。导出帧配置默认跟随当前监视台的共享字符集和断帧方式；可改为沿用记录边界或独立断帧，只处理导出副本。时间戳和 RX/TX 标记使用同一输出编码。
- 通道表格提供独立的数据类型、端序、通道数、帧首、帧尾及校验配置，默认跟随共享数值帧规则。手动修改后仅重解析所选保留原始字节，不改变采集规则、缓冲区或控件波形。通道数与采集一致时包含运算通道，重解析从导出窗口起点重新计算；通道数不一致时只导出新解码的原始通道。勾选“跟随当前监视台帧配置”可恢复自动跟随。大容量数据分批解析和编码，显示进度并检查来源失效和覆盖。
- 默认导出所选来源的完整保留缓冲区，不受当前视口、筛选、可见性及系统响应显示影响；界面显示所选方向的记录数、原始字节数和含毫秒的本地时间范围。原始字节数不等于 CSV 或文本编码后的文件大小。基础原始记录保留未成功解码的字节，数值来源的原始格式仅包含成功解析的数值帧字节。
- RX 与成功发送的 TX 各自保留最多“最大帧数量”条显示记录，TX 导出不受监视台日志条数限制。修改解析规则保留 TX，清空缓冲时一并删除；降低容量淘汰最早显示记录。
- 大于 5 万帧或原始字节超过 32 MiB 时使用 Chrome/Edge 文件保存接口分批写入。激活或删除无关控件不会停止导出；更改所选数据来源、删除对应字节流来源、重建该来源、清空缓冲或记录被覆盖会停止并提示。来源被删除时要求重新选择，不静默切换，建议暂停后导出。

## 8 帧格式说明

基本结构如下：

```text
[可选头部] + [数据负载] + [可选尾部] + [可选校验]
```

示例：

```text
[AB] + [payload] + [0D 0A]
```

如果启用了校验位，校验值位于帧尾之后。

## 9 常见问题

### 9.1 串口无法连接

- 确认浏览器是否支持 Web Serial API。
- 确认页面是否通过本地 HTTP 服务或 HTTPS 打开。
- 检查串口是否已被其它程序占用。

### 9.2 TCP/UDP 无法监听

- 确认已经运行 `npm start`。
- TCP Server 模式下，请填写要监听的本地端口。
- UDP 模式下，请填写本地监听端口；远端 Host/Port 只是发送目标。
- 如果是 TCP Server，请确认该端口未被其它程序占用。
- 注意！目前暂不支持打开两个网页分别作为 Client 和 Server 这种特殊的工作模式。

### 9.3 波形不显示

- 激活波形控件，在右侧“通道配置”中勾选需要显示的通道。
- 检查 Y 轴范围是否合适。
- 切换到自动 Y 轴缩放试试。

### 9.4 发送定时任务异常

- 如果连接断开，程序会自动停止定时发送。
- 出错信息会出现在字节流监视台，不会再弹出浏览器提示框。
