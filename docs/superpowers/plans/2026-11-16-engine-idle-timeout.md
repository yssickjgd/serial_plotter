# 数据引擎空闲断帧与残帧超时

**Goal:** 按已确认方案一，三种模式各自保存空闲时间（毫秒），按后续确认将默认值调整为 50、0 禁用；完整帧解析优先，超时仅清理残帧。已有显式保存值不覆盖。

**Scope:** 原生数据按空闲结束原始记录；数组及自定义协议将未完成字节标为 timeout，保留原始字节、首字节时间戳并重新同步。不改变通道定义、有效采样、通道运算状态或同步采样运行状态。用户后续要求将本轮功能及说明一并提交并推送到远端 main。

**Architecture:** 共享的轻量解析器空闲看门狗，用接收块的 arrival 和可取消定时器工作；历史回放暂停实时时钟，仅按历史 arrival 判定。复用现有 flushPending 并增加原因参数。原始解析器允许零间隔关闭空闲断帧，保留分段上限及换行断帧规则。数据引擎集中应用当前模式时间，保存未激活模式值。
