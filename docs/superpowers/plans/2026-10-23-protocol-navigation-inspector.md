# 协议编辑器导航与属性布局

用户已批准实施：左侧当前协议树形大纲；协议下拉框保持可见；“结构大纲／协议与字段编辑”两个标签，后者在右；字段组件改为通用新建字段；右侧名称常驻，基础／高级／关联三个标签；统一核心配置、数据引擎、控件和编辑器标题；已保存、导入、复制、编辑过的对象删除需居中确认，当前会话刚创建且未编辑的空白项除外。保留现有协议、字段 ID 和全部引用，同步默认 RoboMaster 模板。

## 实施任务

1. 树形大纲、选择／搜索联动、展开状态及操作区迁移；新增有意义的交互回归测试。
2. 右侧名称和三个属性标签，复用现有表单、验证和字段引用；统一侧栏标题与布局样式。
3. 编辑状态跟踪、居中删除确认、引用说明和撤销；新建空白与既有对象区别处理。
4. 默认 RoboMaster 模板适配、配置保存兼容和文档更新；相关测试、完整测试、检查及一次最终独立审查。

## 决策

- 沿用当前包含大量未提交改动的工作区，不切换或清理已有内容；本轮不提交、推送。
- UI 状态保存在现有 editorState，按协议与稳定节点 ID 记录，不写进字段表达式，也不重建协议字段。
- 自动保存不把本会话新建空白项立即标为已编辑；导入、复制和加载模板始终按已有内容处理。编辑后即使撤销也仍需确认。
- 协议既有外部引用保护保持；字段确认框说明失效引用后果，删除后必须修正才能应用。不自动删除依赖规则或改绑。
- 标题、标签和树形导航变化不改动通信边界、CRC、长度表达式或已应用引擎。
- 浏览器自动化此前在本会话被拒绝，本轮不重试或绕过；不声称完成浏览器视觉验收。
