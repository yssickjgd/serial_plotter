# 按命令结构确定帧边界

用户已授权：可独立确定长度的分支不读取 data_length 来断帧。后续确认允许为无法独立确定边界的分支使用长度值表达式，例如 LEN(payload) + LEN(checksum_0)，明确选择“仅验证”或“解析定界＋验证”；仅唯一可解时求解。发送按表达式回填，多个未知长度、循环或无法唯一求解时拒绝。

## 已确认的例外分支

1. 0x0301 子命令 0x0200–0x02FF 的 user_data 最多 112 字节，没有独立终点。
2. 0x0F02 查询/反馈相同命令码，现有模板借助剩余长度 0/1 区分。
3. 未知根命令的原始数据没有独立终点。
4. 未知交互子命令的原始数据没有独立终点。

以上四项用户均已确认可使用表达式参与定界，不需要删除分支或猜测固定长度。最后确认：结构优先，仅无法独立确定边界时求解。

## 新增实施步骤

- 长度规则增加表达式定界选项，编译时关联稳定字段 ID；单个未知 LEN 可用加减乘除求解，非唯一解拒绝。
- 解析将推导出的边界仅用于需要剩余长度的分支，不裁剪已知结构；发送先按实际字节回填再验证。
- 字段属性提供本字段值表达式及用途选择，关联规则可跳转；旧填表关联保留兼容，可显式解除后添加表达式规则。
