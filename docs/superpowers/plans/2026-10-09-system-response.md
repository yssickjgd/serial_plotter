# 系统响应与幅相绘图实施计划

**目标：**在波形控件中分别显示采样波形和系统响应，支持时域、幅频、相频三种模式。

**实现：**继续采用经典脚本；新增独立响应计算模块和只读系统数据视图，复用现有 Canvas、缩放和光标逻辑。所有采集缓冲及普通运算保持原值，不提交或推送现有改动。

**已确认：**系统时域采用零状态单位脉冲响应；按最新需求，数组左侧为 [0]，向右为 [1]；系统幅频默认 dB，可选 10/20 倍 log10 系数；独立采样率未设置时使用归一化频率。两个显示对象分别保留可见通道和视口。

## 重点边界

1. 系统频响必须为真实传递函数，不能把截短冲激响应 FFT 当作精确递归系统响应。
2. 非线性或有非零独立偏置的系统不生成标准幅相响应；参数报错不破坏实时 filter 运算。
3. 零幅值相位、极点及数值溢出产生空点，不连接穿过无效区域。
4. 新定义只使相应静态响应缓存失效；接收新帧不重算静态系统。
5. 切换显示对象不清空采集、不同控件的可见性或原历史视口。

- 归一化频率标签按宽度降低刻度密度；系统视图的 CSV 仍使用实际采集通道及数值。
