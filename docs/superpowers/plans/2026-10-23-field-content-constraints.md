# 字段内容约束统一

用户已批准直接实施：内容约束互斥选择无约束、固定内容、长度关联、校验值；校验起点与终点分别选择是否包含该字段；默认 RoboMaster 模板同步最新设置。

## 实施步骤

1. 为互斥约束、原处编辑、切换确认、兼容旧组合、端点包含及模板编解码增加失败测试。
2. 将长度值和校验表单集中到内容约束；自身读取边界独立、关联信息只读。字段约束与全局规则编辑同一份规则。
3. 起点包含对应 start，不包含对应 end；终点包含对应 end，不包含对应 start。底层保留现有稳定字段 ID 与 edge 表示，偏移表达式保留兼容。
4. 更新 RoboMaster 默认模板的字段约束标记和显式字段边界，保留原协议字节、表达式和 CRC 算法。
5. 更新文档，运行相关测试、npm test、npm run check 和差异检查；一次独立审查并处理必要问题。

## 决策与兼容

- 沿用当前含大量未提交改动的工作区，不切换、覆盖或清理已有工作；本轮不提交或推送。
- 保留字节归为数据类型，不占用四种互斥内容约束；旧配置原样可读。
- 只有主动切换主要约束才停用对应长度／校验规则；规则 ID、字段 ID 和其它表达式引用保留。旧版组合不自动化简，显式选择时说明后确认，支持撤销。
- 校验范围始终采用半开字节区间；两个包含选项只影响字段边界映射，不改变校验算法。
- 浏览器自动化在本会话此前被拒绝，不重试或绕过。以 DOM 交互、样例编解码和源码检查验证，本轮不声称完成视觉验收。
