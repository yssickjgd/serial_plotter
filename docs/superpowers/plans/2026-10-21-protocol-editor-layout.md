# 协议编辑器滚动、分支排版与整数进制

## 已确认范围

- 整帧结构、结构大纲及位段属性完整展示，不分页；中央仅保留一个垂直滚动容器。
- 机器人交互等嵌套分支逐层展开，标题与匹配条件进入正常文档流，内部字段按宽度换行。
- 整型字段独立保存十／十六进制显示选项，同步至样例、结构化字节流及发送；原值、字节、通道运算及 CSV 不变。
- 两处可拖动同一个条件容器内的分支，保留稳定身份和引用；支持键盘、取消及撤销／重做。

## 原因

- `.protocol-editor-body` 和 `.protocol-field-canvas` 同时滚动，面板 `min-height:100%` 叠加兄弟内容产生外层溢出。
- 容器使用 `width:max-content`，分支横向嵌套；分支标题绝对定位，长内容覆盖卡片。
- 通用样式中字段属性仍为多列 grid，右侧拉宽后混合放置完整分支块。
- 结构按 80 项、位段按 30 项分页，后面的字段可能脱离原有父分支显示。
