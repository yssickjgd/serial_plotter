# 协议编辑器字段属性与交互优化

> 在当前工作区实施，保留已有改动及 serial_config.json 的删除状态，不提交或推送。

## 已确认设计

- 点选字段卡片的空白、说明或标题均选中该字段；子字段和分支的操作不冒泡选中父卡片。
- 编辑弹窗占满浏览器页面，保留各窗格的独立滚动及拖动分隔条。
- 属性顺序为字节数、数据类型、字节作用；按宽度筛选类型，不兼容的原草稿保留并提示重新选择。
- 数据类型包括整数、浮点、布尔、文本、原始字节、位段、结构体、互斥分支、重复及 TLV。字节作用包括普通数据、固定内容、保留、校验，并按类型限制。
- 长度和命令仍为普通数值字段，由后续段引用，可同时参与展示与分支。
- “子段 / 结构”统一改为“结构体”；枚举标签及位枚举使用数值／名称表格增删编辑，无需填写 JSON。
- 保留协议字段 ID、存储 schema、原有字段引用和 JSON 导入导出；使用现有经典脚本和控件样式。
- 用户补充：字段属性列出内部引用位置，支持跳转消费者字段及对应属性；高级设置自动展开。
