# 协议编辑器焦点与统一重复配置实施计划

> **For agentic workers:** Use superpowers:executing-plans to implement these tasks inline, with regression tests before fixes.

**Goal:** 修复嵌套、排序及撤销重做的焦点和滚动恢复；所有字段统一使用“重复次数”，移除独立重复段入口并保留 TLV。

**Architecture:** 焦点按稳定字段／分支身份恢复，不按旧数组下标定位；刷新不触发滚动。普通数组沿用 count；结构体增加重复至所属段末的能力，旧 repeat 类型继续解码并在界面投影为结构体，不静默修改旧配置。

**Tech Stack:** 经典 JavaScript 脚本、DOM、现有流式协议引擎和 Node 测试，直接打开 index.html。

**Spec:** 本聊天中 2026-10-24 用户确认：所有类型统一叫“重复次数”，取消重复段，保留 TLV。

## Constraints

- 保留字段、分支 ID、原有引用、旧协议和既有字节布局。
- 固定／表达式次数用于全部适用字段；结构体与 TLV 保留“至段末”。
- 卡片字节数及重复信息同行呈现；不增加分页和横向滚动。
- 本轮不提交、不推送，除非用户另行要求。

## Tasks

- [x] 焦点回归：属性编辑、分支排序后输入框、字段拖动手柄、嵌套、撤销重做及选择项消失时的恢复。
- [x] 修复属性焦点自动滚动、按下标错误恢复分支输入、字段拖动焦点丢失和最近存活祖先回退。
- [x] 统一重复配置及卡片说明，取消重复段选项，旧 repeat 界面兼容。
- [x] 支持结构体按段末重复；校验边界、零进度、跨块、编码及 LEN，不改动旧 repeat/TLV 语义。
- [x] 更新说明，运行相关测试、完整 npm test、npm run check 和差异检查。

验证结果：完整测试 1370 项通过；语法和差异检查通过。浏览器自动化未获授权，本轮未进行浏览器实机验收。边界回归覆盖无界祖先、外层后续字段、旧重复段的多项边界，以及由 FRAME_LENGTH／REMAINING／PARENT_REMAINING 推导的有效长度。

## Review focus

- 排序后同名输入框不能绑定另一分支；焦点恢复不移动任何滚动区。
- 撤销新增字段后回到最近存活的所属结构，避免跳到帧首。
- 重复结构体的字节数仍是每项宽度，旧 repeat 字节数仍限定整个区域。
- 到段末模式只能在可靠段边界内推进；空条目和未消费字节不能造成死循环。
- 新配置保存为结构体，旧协议打开及应用不改写重复字段身份。
