# RoboMaster 2026 V2.0.0 默认模板更新

## 依据与边界

用户提供的 V2.0.0（20260626）PDF，第 1 章串口协议（印刷页 4–43）及 CRC 附录（75–78）。更新默认串口模板，不增加第 2 章 MQTT／Protobuf 客户端。最新“按文档”要求采用官方 data_length = LEN(payload)，替代此前默认示例的自定义 CRC16 计长；已保存的协议保持自身规则，不自动覆盖。

保留协议的稳定 ID 和未改变含义字段的 ID；兼容旧 JSON。编辑器已有“打开当前配置／明确载入最新模板”流程继续使用。保留结构优先、未知分支用明确长度表达式备用定界、独立长度／CRC 规则的架构。

## 实施顺序

1. 按页核对默认模板与 PDF，独立复核中段、尾段及 CRC。先添加新版本失败测试。
2. 更新 robomasterProtocol.js 的来源、官方计长、变化字段及位段、完整串口命令集。移除新版已删除命令和已解决冲突；未定义位保留原始值，不编造含义。
3. 更新 tests/robomasterProtocol.test.js 的独立手工字节样例、完整命令覆盖、任意分块和 CRC 验证；保留旧自定义计长兼容测试。更新其它依赖默认模板的期望。
4. 更新 docs/protocol-editor.md 说明与现有配置升级操作；运行相关测试、npm test、npm run check 和差异检查。不提交或推送。

## 核对重点

- 新增雷达无线链路 0x0A01–0x0A06 与 0x0311；移除 0x0304、0x0F01／0x0F02。
- 0x0003 的 int16 伤害差及敌方建筑血量；0x0201 的 float 射速上限。
- 0x0105／0x0120 位宽变化、RFID 跨字节迁移、0x020C／0x020D 完整位段、uint64 精度。
- 0x0305 双方坐标和 0x0310 300 字节；三处仍有概览／详细表不一致，继续显式提示。
- 多帧粘包、拆包、未知命令，旧配置不会因默认工厂更新而被改写。
