## 已接入的接口

- 核心 v2 节点：fixed、struct、choice、repeat、tlv；choice 以 selector/branches 表示；repeat 使用 count 或 until:end；TLV 使用 headerFields/lengthField/lengthIncludesHeader/lengthUnit/lengthAdjustment。
- Protocol.analyze 提供非抛出式诊断；Protocol.selectBranch 与编解码共用匹配逻辑；record.valid=false 时保留记录但不更新数值输出。
- 编辑器协议库回调：getProtocols、onLibraryChange(schemas,selectedId)、getReferences；状态回调 getEditorState/onEditorState，状态保存在 dataEngine.editorState，不混入协议结构。
- 主代理已接入空库、显式 RoboMaster 模板、删除引用报告与迟到草稿保护；结构化发送支持 TLV 项增删、条件分支及未知原始 V；显示名称和协议库排序变更不重建采集历史。
- 2026-10-21：主代理运行 dataEngine/protocolLibraryApp/protocolSendView 共 37 项通过，包含真实分块 TLV 采集、显式索引映射及重建一致性；完整回归待所有实现代理交付后运行。
