# 波形悬停插值与数组通道扩展（2026-11-19）

## 波形控件

- 幅频图、相频图和系统频率响应在频点较疏时显示点标记，密集区域仍按像素聚合。GPU 绘制与 Canvas 回退使用同一套点和折线。
- 频域悬停按横纵轴刻度在相邻频点之间插值，显示鼠标所在的频率、Bin 位置及各通道幅值或相位。缺失频点和未展开相位的跳变处保持断开。
- 时域悬停的时间和采样点位置使用同一个小数横坐标。在采样率为 1000 Hz 时，第 250 和 251 个采样点正中显示 0.2505 s，对应采样点 250.5。系统时域响应也显示相对于可见窗口左端的小数采样位置。

## Data_Array 通道扩展

- 将每帧从 23 路扩到 25 路时，新原始通道使用 CH00024 和 CH00025。原运算通道顺延，公式、控件绑定及显示设置跟随原通道的稳定身份。
- 应用前校验通道迁移结果并准备解析器。验证失败时保留已生效的规则和数据。
- 切换前已解析的历史保留原帧长和运算结果，新增的原始通道在旧记录中为空。切换时未收完的旧帧保留为残帧。解析器从切换位置开始使用新帧长。

回归用例覆盖线性和对数轴插值、相位缺口、两种绘制路径、23 路到 25 路迁移、解析器初始化失败、历史保留与拆包接收。
