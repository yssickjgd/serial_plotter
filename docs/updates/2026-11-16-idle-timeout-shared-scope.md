# 空闲断帧与全局共用标记更新（2026-11-16）

本次更新集中配置数据引擎的空闲断帧时间，并统一标明共用配置的影响范围。继续直接打开 `index.html` 使用，不新增依赖。

## 空闲断帧与残帧恢复

- 在“数据引擎 → 帧解析 → 空闲断帧”配置时间，单位为毫秒。Raw_Data、Data_Array、Self_Defined_Frame 分别记忆，默认均为 **50 ms**；`0` 禁用，支持非负小数。
- 保留已有显式保存值；仅新配置或缺少该参数的模式使用新默认值。修改仍遵循草稿、校验、应用的流程，切换模式不会覆盖另一模式的时间。
- 原生数据在空闲后结束原始记录。数组和自定义协议仍按原规则立即输出完整帧，只将超时未完成字节标为“超时残帧”，保留原始字节后重新同步。
- 超时不推进无效数值采样，不停止因果同步采样，不清除有效历史或通道运算状态。
- Hex 和按空闲断帧的文本记录跟随当前引擎时间；按换行符断帧的文本保持原规则。导出专用解析配置仍独立于采集。
- 时间戳保留首字节所在接收块的时间，不改成超时触发时刻。判断依据浏览器收到数据块的单调时钟时间，不能将其视为物理串口逐字节时间；过短阈值可能把正常分块交付误判为残帧。

## 历史重建与生命周期

- 修改时间按“重建历史数据”开关处理受影响来源，未激活模式的时间修改不会重建当前输出。
- 历史重建使用保存的到达时间和暂停边界，不以后台执行速度判断超时；重建交接后恢复实时计时。
- 修复暂停、重建后恢复捕获时的超时计时器恢复；清空、模式切换及销毁取消旧回调，避免旧任务回写新状态。
- 支持定时回调晚到时，在下一块到达前检查旧残帧；禁用空闲断帧后仍保留分段上限及暂停／断开的收尾处理。

## 全局共用标记

- 为通讯与缓冲区、引擎解析方式、空闲断帧、数组帧首／帧尾／校验、当前协议、字段映射、因果同步采样、重建历史开关和通道定义统一添加“全局共用”标记。
- 协议编辑器说明应用后的共用范围；文本查看规则继续共用。草稿在应用前不影响正在进行的采集。
- 右侧通道列表明确区分共用名称／颜色和当前控件独立可见性，不将整组配置错误标为共用。
- 波形采样点数随显示对象动态标记：只有“系统响应＋时域图”属于当前控件，其余用途共用全局点数。视口、位姿绑定和导出专用参数保持原作用范围。
- 标记沿用现有样式，窄侧栏允许标题换行，保持标记文字完整。

## 使用说明

已有配置若保存了 1 ms 或其它值，更新后不会被覆盖。需要采用新默认时间时，请在对应模式中填写 `50`，点击“应用解析配置”，再保存配置。
