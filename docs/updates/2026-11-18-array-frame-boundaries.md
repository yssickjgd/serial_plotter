# 数组模式优先匹配帧边界（2026-11-18）

- 数据引擎为 `Data_Array` 时，Hex 和选择空闲断帧的文本优先使用已启用的帧首、帧尾和配置的数组帧长。完整帧识别后立即显示，支持跨接收块拼接，也能切分同一接收块中的多帧。
- 未匹配的字节保留为原始记录，按空闲间隔或分段上限收尾。按换行符查看的文本继续使用所选换行符。
- 原始记录默认分段上限改为 **1024 B**，已保存的显式值继续生效。完整数组帧保留整体，原始分段上限用于未匹配的记录。
- 修改数组边界或空闲时间时，受影响的来源按“重建历史数据”设置处理。历史重建和实时接收使用相同的匹配规则。

回归用例覆盖拆包、粘包、仅帧尾匹配、残帧保留、原始记录分段和历史重建。
