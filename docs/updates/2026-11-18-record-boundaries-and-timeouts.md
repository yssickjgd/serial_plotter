# 拆分原始记录与帧解析设置（2026-11-18）

- 「数据引擎 → 帧解析」保留数组和自定义帧的解析残帧超时。「数据引擎 → 原始记录」管理原始记录空闲间隔和分段上限。两项计时独立保存，默认都是 50 ms，填 0 关闭对应计时。旧配置按原模式的空闲值初始化两项设置。
- 「字节流 → 显示方式」可查看 Hex、文本或解析结果。Hex 的记录边界按控件保存，文本字符集和记录边界全局共用。Hex 和文本都支持「跟随数据引擎」与「仅基本空闲断帧」，文本仍可按换行符切分。侧栏显示当前生效的规则。
- 跟随引擎时优先显示识别出的数组帧或自定义协议帧。未匹配字节按原始记录空闲间隔或分段上限收尾，Hex 和文本均可实时预览待收尾的记录。
- 两项计时的输入框旁加入配置建议。数组和自定义帧模式下，两项计时都开启时建议先设为相同值。需要更快收尾时可单独缩短原始记录空闲间隔，解析器仍按自己的超时设置等待后续字节。

回归用例覆盖旧设置迁移、两项计时独立生效、不同记录边界并存、自定义帧的实时预览与历史重建。
