# 协议编辑器与数据引擎更新（2026-10-24）

本次整理自上次提交以来的协议编辑器开发，以及其依赖的数据引擎、通道、存储和公共工具改造。继续支持直接打开 `index.html`，无需构建。

## 协议编辑器交互

- 编辑器占满浏览器页面，先分左、中、右三列，中央再上下划分结构画布与样例、字节及问题面板；配色和配置卡片沿用主界面。
- 左侧提供可展开、折叠和搜索的结构大纲；“协议与字段编辑”集中放置协议及字段操作，RoboMaster 模板入口固定在左侧底部。
- 右侧采用“基础设置／高级设置／关联信息”，变量名或分支名称常驻顶部；已保存、导入或编辑过的项目删除前需要确认。
- 字段、条件分支和 TLV 分支均可直接点击选中。分支右侧只显示该分支的名称、匹配条件及操作，左侧大纲同步选择；点击子字段只选择子字段。
- 支持字段、子段及分支拖动排序，保留稳定 ID 和引用，并支持撤销、重做。分支排序不改变匹配优先级或解析含义。
- 修复点击分支后焦点回到 `payload`、画布随之跳动的问题；重绘按当前选中对象恢复焦点，并保持滚动位置。普通字段也采用相同处理。
- 取消下拉框的自定义滚轮切换，压缩侧栏间距，消除嵌套滚动和不必要分页；错误、问题列表和样例诊断使用中文并显示关联字段。

## 字段定义与表达式

- 先选择数据类型，始终显示全部支持类型。整数、浮点和布尔类型自动填写字节数并置灰；文本、原始／保留字节、位段、结构体、分支、重复段和 TLV 保留长度配置。
- 数组数量移至基础设置；标量数组的字节数表示每个元素的宽度，切换类型保留数量。
- 每个字段独立选择十进制或十六进制，相关固定值、枚举、分支条件和校验参数同步显示及输入；字节数、偏移、位宽等结构参数继续使用十进制。
- 枚举采用可视化行编辑；位段总长按整字节配置，可划分单个位、若干位及保留位。
- 表达式变量名作为唯一界面名称，保留旧显示标签以兼容配置。检查保留名称冲突；内置变量及函数统一大写并区分大小写。
- 支持 `LEN(payload)` 等字段实际编码字节长度表达式，以及字段引用补全、被引用位置提示和跳转。
- 整帧长度统一为表达式：`0` 表示变长，留空非法；分支可以依据命令值和内部结构独立确定边界。
- 在可选段启用条件及偏移起点旁增加说明和示例，解释不满足条件时不消耗字节、偏移从零开始及留空顺序读取的含义。

## 帧结构与规则约束

- 统一整帧字段树：固定字节、长度与校验存储字段、命令分派、嵌套结构体、互斥分支、重复段和 TLV 均在画布中排列。
- 内容约束统一为无约束、固定内容、长度关联、校验值；字段内编辑与独立“规则约束”页面操作同一规则。
- 长度关系可用 `LEN(payload) + LEN(checksum_0)` 等表达式描述；可仅验证，或在无法独立定界时作为备用解析边界，不能唯一求解时报告错误。
- 规则可选择参与阶段、强／弱规则及发送自动回填；弱规则失败保留数值并标记警告，强规则失败按边界是否可靠决定后续处理。
- 校验覆盖起点和终点分别配置是否包含字段；数据段只读显示长度来源、校验覆盖和关联跳转。
- 支持按字段值选择可视化条件分支及 TLV“重复至段末”，检查匹配歧义、循环依赖、自动回填重叠和无法确定的边界。
- 流式解析保留跨接收块的字节及解析进度，处理断包、粘包和错误重新同步；预编译类型、表达式及规则，减少重复扫描和缓冲复制。

## 默认模板与兼容

- 默认 RoboMaster 模板更新至 2026 V2.0.0（20260626），包含对应串口命令、子命令及 CRC 规则。
- 最新默认模板使用官方定义 `header.data_length = LEN(payload)`，不包含末尾 CRC16；此前保存的自定义 `LEN(payload) + LEN(checksum_0)` 仍继续按用户配置运行。
- 加载新版模板需要显式操作；不会自动覆盖用户已保存的协议。旧协议、字段及消息身份、长度关联和校验范围引用继续兼容。
- 旧标量宽度冲突不会在打开时静默改写，界面提供明确提示和“按类型修正字节数”操作；类型切换不会静默丢弃子字段、约束或引用。

## 配套集成

- 左下集中管理 Raw_Data、Data_Array、Self_Defined_Frame；解析草稿校验后显式应用，控件负责显示和通道绑定。
- 通道统一显示 `CH00001`～`CH65535`，保留编号简写解析；通道名称、颜色、稳定身份、名称引用和补全全局共用，列表采用有限窗口呈现。
- 引入 IndexedDB 异步配置保存和旧配置迁移，保存引擎、协议草稿、通道及界面布局；存储失败不能误报成功。
- 搜索、导出、结构化发送和一键发送接入协议字段及原始字节定位；自动发送固定协议修订，长度、序号及校验按发送规则生成。
- 修复采样点数超过缓存容量时回退、颜色连续选择被中断、通道改名不同步及编辑区多余空白；波形按需跟随浏览器刷新，不再固定限制为约 30 FPS。
- 保留用户删除 `serial_config.json` 的状态；配置通过现有保存、导入和导出功能管理。
