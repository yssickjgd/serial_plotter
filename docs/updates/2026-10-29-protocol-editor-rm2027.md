# 协议编辑器与 RoboMaster 2027 模板更新（2026-10-29）

本次整理自上一笔提交以来的协议编辑器修复、字段重复解析、校验与序号清理，以及 RoboMaster 2027 默认串口模板更新。继续支持直接打开 `index.html`，不新增依赖。

## 协议编辑器

- 修复属性重绘、嵌套分支选择、字段排序及撤销／重做中的焦点跳转与滚动位置异常；按稳定字段／分支身份恢复输入焦点、光标及选中对象。
- “协议操作”依次排列为新建协议、删除协议、导入协议、导出协议、复制协议；数据类型中的“位段”移至首项。
- 所有适用字段统一使用“重复次数”，移除重复方式下拉框与独立重复段的新建入口；旧重复段仍能解析、导入并在界面兼容编辑，TLV 保留。
- 直接输入 `-1` 表示重复至所属段末，`0` 表示不读取，正整数或表达式表示次数；表达式结果必须为非负整数，计算得到 -1 不代表段末。
- 卡片在字节数后同行显示重复信息，默认单次不显示额外文字。无法可靠定界、单项长度不明或条目不推进时提供具体原因。
- 断帧角色的界面名称统一为“帧头／帧尾”，原有配置值及字段引用保持兼容。

## 解析、校验与发送

- 统一接收扫描、完整解码、编码、LEN、字段映射、补全和发送表单的重复语义；覆盖数值、布尔、位段、固定／原始字节、文本、结构体及分支。
- 修复重复项边界、自动回填、TLV 内部重复和工作线程解析的一致性，检查不完整条目、负次数、零进度及循环依赖。
- 所有校验算法提供初始值、输出异或值和结果按位取反。取反按 8／16／32 位校验宽度进行；CRC 位反射单独配置，默认校验结果保持不变。
- 内置自动序号只保留 `SEQ`；旧内置 `SEQUENCE` 引用按作用域迁移，真实同名字段及其成员引用保持原意。
- 协议符号版本升级为 3，全局通道符号版本仍为 2；移除迁移时强加的协议专用字段前缀及通用提示，已保存的实际字段名称和身份保留。

## RoboMaster 2027 V1.0.0（20261029）

默认模板依据用户提供的 PDF 第 1 章串口协议（3–45 页）及 CRC 附录（75–78 页），覆盖 32 个根命令、8 个固定交互子命令及 `0x0200–0x02FF` 机器人间通信范围。第 2 章 MQTT／Protobuf 不属于串口模板。

| 数据 | 主要变化 |
| --- | --- |
| 血量 `0x0003` | 24 字节，包含 R／B 前哨血量及双方累计控制度 |
| 场地事件 `0x0101` | 8 字节，两组 uint32 位段，按新版阵地及增益点定义 |
| 伤害 `0x0206` | 7 字节，新增命中序号及 int16 命中坐标 |
| RFID `0x0209` | 6 字节，第二组扩展为 uint16，更新点位分配 |
| 雷达状态 `0x020E` | 8 字节，新增装甲加固机会及圆心、半径 |
| 雷达指令 `0x0301 / 0x0121` | 子内容为 13 字节，新增加固请求和圆心 |
| 无线场地／增益 `0x0A04 / 0x0A05` | 分别为 12／47 字节，更新位段、保留区域及加固信息 |
| 自定义终端指令 `0x0311` | 60 字节 |

- 同步更新重装机器人及保留区域；不再沿用保留位置的旧业务含义。20 个打包字段采用显式位段，命令分支默认十六进制显示。
- 移除新版未列出的 `0x0302 / 0x0306 / 0x0309`，未知命令仍保留原始数据；移除新版已解决的三处长度冲突提示和发送布局选择要求。
- 长度仍采用官方 `header.data_length = LEN(payload)`；帧头 CRC8、整帧 CRC16 保持独立规则，参数经新版附录复核无需变更。
- 协议与未改变含义的字段继续使用稳定 ID，已保存的旧协议不自动覆盖；ID 中的旧年份不代表模板文档年份。

## 如何载入新版模板

在协议编辑器中选择“协议与字段编辑 → RoboMaster 模板”，确认“载入最新模板”，检查通道映射后点击“应用协议”。替换草稿可撤销；实际历史处理仍遵循“重建历史数据”配置。
