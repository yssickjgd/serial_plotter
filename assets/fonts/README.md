# 中文字体

`noto-sans-sc.woff2` 是 Noto Sans SC 可变字体的 WOFF2 格式转换版本，保留完整字形与字重轴，供页面离线显示中文。原始字体为本机安装的 `NotoSansSC-VF.ttf`；转换使用 fontTools 4.51.0。

字体单独采用 [SIL Open Font License 1.1](OFL.txt)，版权和完整授权条款见同目录文件。上游项目：[Google Fonts / Noto Sans SC](https://github.com/google/fonts/tree/main/ofl/notosanssc)。项目本身的许可声明不替代字体许可。
